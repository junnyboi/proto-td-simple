# Figtree font source

`Figtree.ttf` is the unmodified upright variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/figtree), with weights 300–900. Runtime font resources select regular body text and the intended heading weights. Its permanent CDN URL is recorded in `assets.lock.json`.
