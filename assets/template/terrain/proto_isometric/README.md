# Proto Isometric Terrain Assets

These terrain textures and elevated obstacle sprites were copied from [`junnyboi/proto-isometric`](https://github.com/junnyboi/proto-isometric) at commit `93153530c98a243be1590dd690ac013698e6077f` for the Agent 4 map-display transplant.

`res://scripts/view/proto_isometric_terrain.gd` uses the 512×512 terrain textures as repeating UV-mapped materials across `IsoProjection` diamonds. It uses the obstacle sprites on blocked raised cells and renders deployable elevated cells as textured source-style blocks so the battle model’s placement semantics remain readable.
